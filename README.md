# ООО «Морской вектор» — корпоративный сайт

Статический сайт: чистый HTML + CSS + JS, без сборщиков и зависимостей.
Загружается на любой хостинг как есть (корень домена).

## Структура
```
index.html                  Главная
about.html                  О компании
tlk.html                    ТЛК «Колядичи» (комплекс класса «А»)
fleet.html                  Автопарк
geography.html              География перевозок (карта маршрутов)
services.html               Услуги (обзор)
services-avto.html          Автомобильные перевозки
services-temp.html          Температурный контроль
services-int.html           Международная логистика
services-warehouse.html     Ответственное хранение
services-container.html     Контейнерная площадка
clients.html                Клиентам (+ FAQ)
partners.html               Партнёрам
career.html                 Вакансии ← по образцу с фото
news.html                   Новости
contacts.html               Контакты + форма заявки
privacy.html                Политика обработки перс. данных
sitemap.xml, robots.txt
assets/css/style.css        Все стили (тёмная тема navy + голубой акцент)
assets/js/main.js           Меню, аккордеоны, фильтры вакансий, модалка отклика, формы
assets/img/favicon.svg
```

## Логика сайта
- Меню: О компании (5 подпунктов) · Услуги (6) · Клиентам · Партнёрам · Вакансии · Контакты.
- Переиспользуемая шапка/футер/CTA — правится в одном месте (исходники сборки в папке `site/`, на хостинг её выкладывать не нужно).
- Страница вакансий: фильтры по направлениям, аккордеон «чем предстоит заниматься / ожидаем от Вас / предлагаем»,
  голубой блок «Подробнее о вакансии по тел.», метка «перспективная вакансия», кнопка «Откликнуться на вакансию» → модальная форма с автоподстановкой вакансии и загрузкой резюме.
- Формы сейчас демонстрационные (показывают сообщение об успехе). Для реальной отправки нужно подключить
  обработчик на бэкенде или сервис (Formspree, SendGrid, CRM) — скажите, какой вариант удобнее.

## Технические заметки
- Адаптив: 1440 / 1280 / 1080 / 860 / 390 px проверен, горизонтального скролла нет.
- SVG-графика (тягач с рефом, схема ТЛК, карта маршрутов) — вектор, масштабируется без потерь, весит копейки.
- Доступность: aria-атрибуты на аккордеонах и модалке, focus-состояния, поддержка `prefers-reduced-motion`.
- IIIF/внешних зависимостей нет, кроме шрифта Inter с Google Fonts (можно локально положить).
- Классы БЭМ-подобные, стили в одном файле — легко передать в разработку или встроить в CMS (1С-Битрикс, WordPress).
